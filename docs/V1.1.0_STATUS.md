# v1.1.0 requirement status

This checklist records how the v1.1.0 specification is addressed.

| Area | Status | Implementation / notes |
| --- | --- | --- |
| TUI flicker | Done | Curses retained; bounded writes plus `noutrefresh()`/`doupdate()` frame commits. See the framework evaluation. |
| Framework evaluation | Done | Textual, prompt_toolkit, curses, and Bubble Tea trade-offs documented; no Go migration. |
| Empty search clearing | Done | Empty Search submission clears Results and invalidates stale workers. |
| Search word editing | Done | Curses key constants and raw xterm Ctrl-left/right/Ctrl-backspace sequences are normalized. |
| Persistent listening recommendations | Done | History is persistent; Liked Songs is the primary recommendation source. |
| Suggestions disappearing on selection | Done | Playing a suggestion does not mutate the suggestion list. |
| Pane navigation | Done | Ctrl-h/l and Ctrl-left/right remain global pane controls; search consumes word-navigation keys first. |
| Related queue playback | Improved | Radio results are deduplicated, music-filtered, version-ranked, and artist-scoped on fallback. YouTube does not expose reliable genre metadata through every flat result, so genre matching remains best-effort. |
| Loading/Playing/error states | Done | Loading, Playing, Paused, Stopped, Network Error, Playback Error, Search Error, and No Results are displayed. |
| `addnwstr()` | Done | Bounds and wide-character fallback are handled in the renderer; the fix is not Ghostty-specific. |
| Search version ranking | Done | Query intent, title/artist matching, official signals, and negative alternative-version signals are combined without excluding explicit versions. |
| Termux MPV linker issue | Deferred | No MPV binary, Android library, or playback dependency changes; documented in `KNOWN_ISSUES.md`. |
| Ctrl+C | Done | TUI catches KeyboardInterrupt, closes playback, and `main()` returns 130 without a traceback. |
| Termux touchscreen | Best effort | Terminal mouse reporting maps taps to panes/rows when the emulator forwards events; keyboard support is preserved. |
| Windows PowerShell install | Done | `install.ps1`, `windows-curses` extra, PATH checks, and winget integration are included. |
| Network/error states | Done | yt-dlp/MPV failures classify network failures separately from search/playback failures. |
| Seek/next/previous | Done | Shift-arrow seek and h/l next/previous remain available from all panes. |
| Faster live suggestions | Done | Debounced background requests, per-prompt cache, and generation checks prevent stale overwrites. |
| Data transparency | Done | `DATA_STORAGE.md` documents files, formats, retention, deletion, and external communication. |
| Liked Songs | Done | Protected system playlist; song-level add/remove/download/delete operations remain available. |
| Liked Songs cache | Done | Signature and compact artist/token metadata invalidate when playlist contents change. |
| Suggestions cache | Done | Recommendations load immediately from JSON and refresh in the background when needed. |
| Persistent dismissals | Done | `D` records dismissed URLs until `R` manually refreshes and clears the set. |
| Manual Suggestions refresh | Done | `R` generates a fresh batch and resets dismissals. |
| `--update` | Done | GitHub latest-release check followed by pipx upgrade (or pip fallback) with clear status. |
| Automatic release detection | Done | Asynchronous GitHub check, timeout, cached result, once-per-release notification, and non-blocking overlay. |

`Buffering` and `Offline` are retained as state vocabulary for future MPV
property monitoring. v1.1.0 reports the more reliable states available from the
current MPV process/IPC contract rather than guessing a transient buffer state.
